## Who am I?

I work in Security Operations — monitoring infrastructure, triaging incidents, and analyzing
threats and anomalies at scale. What started as a networking background grew into a real
obsession with how systems break, which pulled me toward offensive security.

Today I sit on both sides of that line: I defend production environments using SIEM,
log analysis, and hardening practices, and I train offensively so I understand what I'm
defending against. I learn best by doing, so most of my growth happens in labs and on
deliberately broken machines rather than slides.

## What am I currently working on?

- 🎯 **OSCP prep** — full-time study focus; hands-on exploitation, privilege escalation, and report writing.
- 🧪 Grinding **HackTheBox** and **TryHackMe** for practical offensive reps.
- 🛠️ Building **bash automation for recon workflows** — chaining AutoRecon → Gobuster → Gowitness
  to auto-enumerate web services and screenshot every discovered path (published here).
- 🐧 Writing **Shell scripts** to strip repetitive steps out of pentest and SOC routines.
- 📄 Producing clean technical documentation: incident procedures, detection notes, and findings write-ups.

### 🔭 Featured project
**Web recon automation pipeline** — one command takes a target IP, runs full service discovery,
directory brute-force, and captures screenshots of every live endpoint found. Built for low-RAM
VMs (4.3 GB), with per-target result folders and deduplicated URL lists.
